Personal Expense Tracker 💰
About the Project

Personal Expense Tracker is a simple and responsive web application developed to help users manage and track their daily expenses. It provides an easy way to record expenses, organize transactions by category, and monitor spending.

The application is built using HTML, CSS, and JavaScript. It uses browser LocalStorage to save expense records.

Features
Add new expenses with name, amount, category, and date.
View total expenses.
Track current-month spending.
Search expenses by name.
Filter expenses by category.
Delete expense records.
Export expense records to CSV.
Save data using browser LocalStorage.
Responsive design for desktop and mobile devices.
Display amounts in Indian Rupees (INR).
Technologies Used
HTML5
CSS3
JavaScript
Browser LocalStorage

How to Run the Project
Download or clone this repository.
Open the project folder.
Open the index.html file in your web browser.
Start adding and managing your expenses.

No additional software installation or dependencies are required to run the application.

How to Use
Enter the expense name.
Enter the amount.
Select an expense category.
Choose the date.
Click the Add Expense button.
View your spending summary and transactions.
Search, filter, or delete expenses as needed.
Use the Export CSV button to download your expense records.
Data Storage

The application stores expense records in browser LocalStorage. Data remains available in the same browser unless the browser storage is cleared. Expenses are not synchronized across devices.
